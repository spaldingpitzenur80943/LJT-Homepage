# LJT-Homepage

Personal homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Pages

- About (`/`): academic background, research experience, skills, publications, and contact information.
- Publications (`/publications/`).

## Deployment

The GitHub Actions workflow in `.github/workflows/jekyll.yml` builds the site with Jekyll and publishes the generated site to the `gh-pages` branch. GitHub Pages can serve the site from that branch with the configured `/LJT-Homepage` base URL.
